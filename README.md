🎯 QuizCraft – Interactive Quiz Web App

QuizCraft is an interactive quiz web application built using React and Vite. It helps users test their knowledge of web development through multiple-choice questions in a simple and user-friendly interface.

✨ Features

- Interactive Quiz: Answer multiple-choice questions on web development.
- Timer: Get 20 seconds to answer each question.
- Categories: Choose from HTML, CSS, JavaScript, Programming Basics, or All Topics.
- Difficulty Levels: Filter questions by Easy, Medium, or All Levels.
- Shuffled Questions: Questions are shuffled to make each attempt more interesting.
- Score Tracking: View your performance after completing the quiz.
- Answer Review: Review your selected answers and the correct answers.
- Restart Quiz: Try again and improve your score.
- Responsive Design: A clean, colorful interface designed for a pleasant user experience.

🛠️ Technologies Used

- React
- Vite
- JavaScript
- HTML
- CSS

🚀 Getting Started

Follow these steps to run QuizCraft on your computer.

Prerequisites

Install "Node.js" (https://nodejs.org/) and npm.

Installation

1. Clone this repository:
   
   git clone https://github.com/srishtisawhney22-svg/QuizCraft.git

2. Open the project folder:
   
   cd QuizCraft

3. Install the required dependencies:
   
   npm install

4. Start the development server:
   
   npm run dev

5. Open the local URL displayed in your terminal, usually "http://localhost:5173/".

🏗️ Build for Production

To create a production build, run:

npm run build

To preview the production build locally, run:

npm run preview
